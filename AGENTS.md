## Agent skills

### Issue tracker

Issues and specs live in local markdown under `.scratch/<feature>/`.
Read `docs/agents/issue-tracker.md` when creating or updating work items.

### Triage labels

Use the five default triage roles.
Read `docs/agents/triage-labels.md` when assigning issue status.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Read `docs/agents/domain.md` before exploring the codebase.
